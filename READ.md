## 📚 Topics Covered

### 1. Generative AI

Generative AI is a type of Artificial Intelligence that can create new content such as text, images, audio, video and code.

### 2. Large Language Models

LLM stands for Large Language Model. LLMs are AI models trained on large amounts of text data to understand and generate human-like language.

Important concepts include:

- Training
- Parameters
- Inference
- Next-token prediction

### 3. Tokens & Context Windows

A token is a small unit of text processed by a language model.

A context window is the maximum amount of information an AI model can consider during an interaction.

Tokens and context windows affect how much information a model can process.

### 4. Transformer Architecture

Transformers are neural network architectures widely used in modern language models.

Important concepts include:

- Tokenization
- Embeddings
- Attention mechanism
- Transformer layers
- Output probabilities

Simplified workflow:

Text Input → Tokenization → Embeddings → Attention Mechanism → Transformer Layers → Output Probabilities → Generated Text

### 5. Types of Generative AI Models

- Text Generation
- Text-to-Image
- Speech and Audio
- Text-to-Video
- Multimodal Models

### 6. AI Hallucinations

AI hallucination occurs when an AI system produces information that is incorrect, unsupported or fabricated while presenting it in a convincing way.

Possible causes include:

- Incomplete information
- Ambiguous prompts
- Patterns learned during training
- Lack of relevant knowledge

Ways to reduce hallucinations:

- Use clear prompts
- Provide relevant context
- Verify important information
- Use reliable sources
- Apply human review

### 7. AI Bias & Limitations

AI bias can occur when an AI system produces systematically unfair or unbalanced results.

Possible sources include:

- Training data
- Data collection
- Human decisions
- Model design
- Evaluation methods

Common limitations include:

- Hallucinations
- Incorrect information
- Bias
- Limited knowledge
- Ambiguous responses
- Privacy and security concerns

### 8. Responsible AI

Responsible AI means developing and using AI systems in a safe, fair, transparent and accountable manner.

Important principles include:

- Fairness
- Transparency
- Privacy
- Safety
- Accountability
- Human Oversight

### 9. Generative AI Application Architecture

Basic architecture:

User → Application Interface → Prompt/Input Processing → AI Model → Output Processing → User

Advanced applications may also include:

- Databases
- Document Retrieval
- External APIs
- Safety Filters
- Authentication
- Logging
- Monitoring

### 10. Prompt Engineering

Prompt engineering is the process of designing clear and effective instructions for an AI model.

Example:

"Explain Artificial Intelligence in simple words for a beginner."

Good prompts can specify:

- Task
- Topic
- Audience
- Format
- Level of detail
- Examples
- Constraints

### 11. AI Model Comparison

Different AI models are designed for different purposes.

| Model Type | Main Use |
|---|---|
| Text Generation | Text, answers, summaries and code |
| Text-to-Image | Creating images from text |
| Speech & Audio | Speech recognition and audio generation |
| Text-to-Video | Creating videos from prompts |
| Multimodal | Processing multiple types of information |

Important comparison factors:

- Output Quality
- Speed
- Context Handling
- Input and Output Types
- Cost
- Safety
- Accuracy
- Application Requirements

### 12. AI Output Comparison

The same prompt can produce different styles of responses depending on the model, prompt, context and generation settings.

Example prompt:

"Explain machine learning to a beginner."

Different response styles explored:

- Short Response
- Detailed Response
- Example-Based Response

This experiment demonstrates the importance of prompt design and output evaluation.
